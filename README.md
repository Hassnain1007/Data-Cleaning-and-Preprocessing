# Data-Cleaning-and-Preprocessing
This repository houses a data cleaning project that uses the Netflix Movies and TV Shows dataset available at Kaggle. Through the use of Python and Pandas, the dataset undergoes data cleaning procedures such as the detection and management of missing values, duplicate deletion, cleaning and standardizing text columns, formatting date columns, and feature extraction like the year when the content was released and duration values. This project illustrates important data cleaning steps carried out in data analytics and data science projects.
